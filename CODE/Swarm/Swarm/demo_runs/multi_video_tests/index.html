Demo Narrative

Before calibration: agents mostly trust their own packets because heterogeneous embeddings are not aligned.

After calibration: warm-up frames train projection heads, making peer packets reusable across backbones.

Honest claim: this is lightweight adaptation for inference-time transfer, not full offline model training.
